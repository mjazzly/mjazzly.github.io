The words on this page

  • Build. One of the AI systems on the AI Work page, each with its own test cases, checker and pass rule.
  • Case. One test input with a known right answer, written down before the first run. A run matches a case when its result equals that answer.
  • Gate. A case where the build must stop and ask, or decline the task. The gate is held when the code did so.
  • Bar. The build's own pass rule, such as every case matched and every gate held. The bar is met or not met; there is no partial credit.
  • Smallest passing. The cheapest model that meets a build's bar. The cost of a full sweep adds up one run per build on that model.
  • Sweep. One run of every build on every model, started by one command and compared with the sweep before it.
  • Counted run. A run that reached the model, finished, and could not have seen its expected answers. Any other run is refused and stays on the record uncounted.
  • Version. One numbered state of a build's rules. It moves only after a run, and the run that earned it is on the record.
