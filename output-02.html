The words on this page

  • Schema. The one shape every file is merged into: nine fields, each with a type and the header names it is known by.
  • Header. The row that names a file's columns. The run finds it, even below title rows, and logs where it was.
  • Mapping. Which schema field a column feeds. The model proposes it with a reason; the code checks the values fit before anything is merged.
  • Set aside. A title row, a blank line or a totals row. It is logged with the reason and never merged.
  • Held. A value that fails its type, such as a word in a quantity column. The row is kept aside with the reason and never rewritten.
  • Reconciliation. The count that closes every file: rows read equal rows merged plus rows held plus rows removed.
  • Decision log. One line for every step the run took, each with its reason, in the order it happened.
  • Run. One pass over the folder by one model, recorded with its id, its tokens and its cost.
