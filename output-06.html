The words on this page

  • Round. One contact export run through every stage once, with its own run record.
  • Row key. The name the code gives each row when it reads the export. The run record uses it instead of a name or an email.
  • Stop. A point where the run halts and prints a count. It goes on only when that stop is confirmed, and a count confirmed wrong halts it. Also called a guardrail. Because it waits for a person to confirm, the field calls it human in the loop.
  • Scope. The rules in code that keep the US and Canada, take out a blank or broken email, and keep the first of two rows with one email.
  • Seniority floor. The level a job title must reach to stay: director and above. The model reads the title; the code applies the floor.
  • Verdict. What the email validation stub says of an address: valid and suspect stay, invalid, honeypot and no result leave.
  • Run record. The file every round writes, complete or halted: the counts, the stops, every exclusion and its reason, the model and the cost.
