Operating principles

Foundations first, then automate

Automation built on an unexamined process just makes mistakes faster. I map the workflow, fix the data quality, then build the system.

Validate before deployment

Every number and every AI-assisted output passes verified checkpoints before it reaches a stakeholder. Speed is only useful when the answer is right.

Document so it survives handover

A system that lives in one person's head is a liability. Everything I build ships with versioned guides a colleague can run without me.
