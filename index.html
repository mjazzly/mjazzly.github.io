Operating principles

Foundations first, then automate

Automation built on an unexamined process just makes mistakes faster. I map the workflow, fix the data quality, then build the system.

Validate before deployment

Every number and every AI-assisted output passes verified checkpoints before it reaches a stakeholder. Speed is only useful when the answer is right.

Document so it survives handover

A system that lives in one person's head is a liability. Everything I build ships with versioned guides a colleague can run without me.

Output validation and the versioned data playbook

SYS-03 / Packaged AI assistantsIn use

Modular assistants with executable documentation

Recurring workflows converted into packaged AI assistants: structured guides, reference documentation, and executable scripts that ensure the same process runs the same way every time, regardless of who runs it.

SYS-04 / Data quality pipelineIn use

Validated data expansion for a client CRM

A multi-stage pipeline for expanding a client's contact database: source export, identity and email validation, fit scoring against the target profile, deduplication against the CRM, then a CRM-ready file with a per-record status. Over 2,700 validated records delivered, each round logged in a quality ledger.

Impact: every record carries its validation status before import; every round is auditable

SYS-05 / Reporting pipelineIn use

Multi-source reporting pipeline, single source of truth

A Power Query pipeline consolidating 20+ performance metrics from five source platforms (CRM and paid channels) into one governed table feeding the client dashboard, for US client accounts in HR technology, enterprise SaaS, industrial technology, and payments. Every transformation rule is documented and inspectable.

Impact: weekly manual reporting preparation reduced by over 90%
