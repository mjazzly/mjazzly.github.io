The report that ate Mondays

CASE-01 · REPORTING PIPELINE
Situation

A weekly performance report for a US-based client pulled 20+ metrics from five advertising and CRM platforms: Google, Bing, LinkedIn, Meta, and Salesforce. Every Monday, hours went into exporting, reconciling, and reformatting the same numbers by hand. The report was accurate, but the person producing it was the pipeline.

Constraint

No data warehouse, no engineering support, and no budget for new tooling. Whatever the solution was, it had to run inside the tools already on the desk and be simple enough for a colleague to operate during handover or leave.

System

A Power Query pipeline that ingests each platform export, standardises naming and formats, applies the cleaning rules that were previously tribal knowledge, and lands everything in a single source of truth table feeding the client dashboard. The transformation logic is documented step by step, so the pipeline is inspectable rather than magical.

Result

Weekly manual preparation time down over 90%. Reconciliation errors near zero because the rules run identically every week. Monday mornings returned to analysis instead of assembly, and the process survived a full handover test: someone else ran it without me in the room.
